# 0.1.0-rc.3.5 预发行说明

适配官方 Windows 客户端 `13.3.5.564315535`，目标为 Ubuntu 26.04 x86-64、GNOME Wayland／XWayland、PipeWire、Vulkan。兼容包版本与抖音客户端版本分别维护。

本版在 rc.3.4 的基础上只增加启动器侧能力，运行产物与 Wine 模块沿用 rc.3.4 已验证集合；未重新编译采集二进制，也未重做完整空前缀安装验收。

## 本版变更

| 分类 | 结果 | 位置 |
| --- | --- | --- |
| 渲染后端开关 | 新增 `--ui-renderer {default,vulkan}`（默认 `default` 发行行为不变）；Vulkan 候选在本地黑盒复测中把内容追帧中位从 56–60 ms 降到 22–26 ms、CPU 反而更低，但共享／录制／音轨／开播未复验，保持 opt-in | `tools/felix_live.py`、[分段测量](docs/UI_RESIZE_ASSESSMENT.md#黑盒复测与受控开关2026-11-21) |
| 拖拽缩放辅助进程 | 会话启动后默认拉起 `tools/ui_resize_preview.py`：8 方向透明抓手＋顶部移动条、10 次/秒门控 `_NET_MOVERESIZE_WINDOW`、冻结帧等比拉伸覆盖、松手后等内容连续稳定两帧再交接（避免闪动）；`--no-ui-resize` 可关闭 | `tools/ui_resize_*.py`、[设计说明](docs/UI_RESIZE_HELPER.md) |
| 尺寸下限 | 不再继承写死的 1280×720，改为跟随应用自身最小值（直播伴侣实测 1080×720），并采纳窗口实际几何为新基准 | `tools/ui_resize_grips.py` |

## 验证范围

- 辅助进程：本机日常入口启动后 `attach` 成功、9 个抓手布局正确；程序化拖拽（`wmctrl`/`_NET_MOVERESIZE_WINDOW`）与真实鼠标拖拽均验证窗口跟手、松手不弹回；冻结帧覆盖层随窗口拉伸，收尾交接无闪动（用户实测确认「视觉效果可以」）。
- 渲染开关：`--ui-renderer vulkan` 的客户端 GPU 进程命令行已确认带 `--use-angle=vulkan`；黑盒 A/B 数据见 `docs/UI_RESIZE_ASSESSMENT.md`。
- 未复验：本版没有重新做从零安装、共享／录制／音画／开播与长时间稳定；这些仍以 rc.3.4 的历史结果为准。
- 已知边界：拖拽期呈现的是「按窗口尺寸拉伸的冻结帧」，不是实时重排——应用在拖拽时不重排是 Wine 侧每次约 40 ms 的成本决定；外框方案只能遮蔽这段时间。

## 回退与关闭

- 关闭辅助进程：`felix_live.py launch --root <安装目录> --no-ui-resize`
- 回退渲染后端：默认即 `--ui-renderer default`，无需操作
- 日志：`$XDG_RUNTIME_DIR/<unit>/ui-resize.log`

本版对应仓库 `main` 上 `1e9f7dc` 之后的统一提交（含 `--ui-renderer` 与拖拽缩放辅助进程）。
