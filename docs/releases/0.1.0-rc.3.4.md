# 0.1.0-rc.3.4 预发行说明

适配官方 Windows 客户端 `13.3.5.564315535`，目标为 Ubuntu 26.04 x86-64、GNOME Wayland／XWayland、PipeWire、Vulkan。当前实测 GPU 为 NVIDIA RTX 4060；未覆盖所有发行版、桌面或显卡。兼容包版本与抖音客户端版本分别维护。

本仓库此前公开源码基线为 `c254dd5c80f6993ecdb9157fd8268a6064fc738d`，尚无 GitHub Release。本次将其后的 11 个兼容提交及发行文档整理为首个公开预发行包，沿用已验证 RC3.4 的 12 个运行产物。重新组包并不等同于本轮重新编译或重新完成整套桌面验收。

## 验证范围

- 基础从零安装已使用官方 x64 安装器，核对安装器 SHA-256、首次启动、全屏和窗口授权、本地录制中的视频及 8 秒测试音。RC1 另有空前缀的入口、托盘及多窗口验收。
- RC3 从零安装后做了 UI 验收；后续补充未再做完整空前缀重装。用户取消了该轮重复媒体验收，不能将历史音画结果写成本包本轮新测结果。
- RC3.3／RC3.4 在原 Dock 运行实例中各做了相关连续缩放及真实最小化恢复验证，动态测试画面和媒体进程保持。RC3.4 有 336 次尺寸变化的验证记录。
- 本次发行核对包内源码与已验证 RC3.4 对应、12 个运行产物 SHA-256，以及独立 Xvfb 的表面和退出确认框专项测试。发行附件的复核结果另外登记于 `RELEASE_VALIDATION.json`，不包含账号前缀或原始桌面日志。
- 早期隔离候选通过短时全屏／窗口推流端检查；本次没有重新开播、验证观众端或长时间稳定性。

分阶段证据见 [安装验收](../CLEAN_INSTALL_TEST.md)，UI 性能限制见 [分段测量](../UI_RESIZE_ASSESSMENT.md)。

## 已知限制

- 整体缩放流畅度仍未达到原生客户端体验。首次打开可能短暂停顿，扩大时仍可能有残余闪动。
- 最大化还原后尺寸每次增加约 8×10，在默认及实验 Vulkan 配置均复现，尚未处理。
- 系统授权后伴侣自带选择框可能短暂闪过；按用户决定暂缓。
- 退出确认框曾出现约 8 秒超时，继续保留诊断记录；24 毫秒设置未改。
- ANGLE Vulkan 仅为独立实验，高频 CPU 增加且没有新媒体回归，不随本包默认启用；真实 GPU 调度优先级控制未实现，也不包含实验 0075。
- 官方服务、客户端自动更新、账号资格、代理和 DNS 可能影响开播。兼容包不修改宿主路由、DNS 或 VPN；入口沿用本实例的直连选项。

## 下载与安装

下载同一发行下的 `felix-live-compat-0.1.0-rc.3.4-linux-x86_64.tar.gz` 和 `SHA256SUMS`，在下载目录执行：

```bash
sha256sum --check SHA256SUMS --ignore-missing
tar -xf felix-live-compat-0.1.0-rc.3.4-linux-x86_64.tar.gz
cd Felix-Live-Compat
/usr/bin/python3 -B tools/felix_live.py preflight
```

从官方下载 Windows x64 安装器，按[安装说明](../INSTALL.md)安装到新的空目录。包内提供兼容源码、Wine 补丁和相应运行产物；官方客户端、安装器、商标图片、账号前缀和私有日志不随包分发。完整运行器与 wrapper 由安装工具从固定地址获取并校验，约需额外数百 MB 下载，本包不是包含全部依赖的离线安装器。

## 回退

本次上传不会自动更新本机安装或 Dock。测试新包时使用新的安装目录；现有实例保持原状。回退时正常退出新实例，使用旧安装自己的入口。已有 RC3.3 安装只回退 RC3.4 维护优化时，可在停止伴侣后恢复旧包内的 `window_surface_state.py`；不要热换使用中的 Proton 模块。跨版本回退依赖安装前保留的完整前缀及组件备份，不将新的账号状态盲目覆盖到旧前缀。

Wine／Proton／DXVK 来源和许可证见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。Wine 模块的固定基础源码地址及哈希在 `assets.json`，本包包含完整增量补丁和构建脚本。后续路线一仅为[研究规划](../NATIVE_UI_ROUTE_ONE.md)，本次尚未移植 Linux 界面。
