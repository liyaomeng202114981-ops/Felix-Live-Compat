# 0.1.0-rc.3.6 预发行说明

适配官方 Windows 客户端 `13.3.5.564315535`，目标为 Ubuntu 26.04 x86-64、GNOME Wayland／XWayland、PipeWire、Vulkan。

本版只增加「原地更新」能力：运行产物、Wine 模块与客户端版本沿用 rc.3.5 已验证集合；未重新编译采集二进制，也未重做从零安装验收。

## 本版变更

| 分类 | 结果 | 位置 |
| --- | --- | --- |
| 原地更新（patch 模式） | 新增 `felix_live.py patch --root <安装目录>`：刷新 `payload/`、匹配的 Wine 补丁模块、前缀注入（system32 文件、`wgc.reg`、DLL overrides）、启动器与 helper，并重注册桌面入口；保留 runner、前缀与已安装客户端，不重新下载 805 MB/1.6 GB runner | `tools/felix_live.py`、[说明](docs/PATCH_INSTALL.md) |
| 前置校验 | 要求存在 `runner/proton`、`prefix/pfx` 与官方客户端；系统 Wine 或没有客户端的前缀会被明确拒绝；要求在桌面会话内运行（否则报错，不会挂在 `wine regedit`） | 同上 |
| 幂等 | 可重复执行，覆盖的均为 kit 管理文件 | 同上 |
| 安装目录同步 | 随包更新 `launcher/tools`、`launcher/src` | 同上 |

## 验证范围

- 在已有 rc.3.5 安装上：停止会话 → 执行 `patch` → 重新启动，runner／前缀／客户端均未重建；helper `attach` 成功、9 个抓手布局正确，并捕获到真实鼠标 `press`／`drag`（移动条方向 8）。
- 负向验证：不存在的安装目录、空目录、无 patched runner 的目录均给出对应错误，未修改任何现有文件。
- 未复验：本版没有重新做从零安装、共享／录制／音画／开播与长时间稳定；这些仍以 rc.3.4／rc.3.5 的历史结果为准。

## 使用方式

新安装：

```bash
tar --zstd -xf felix-live-compat-0.1.0-rc.3.6.tar.gz
cd Felix-Live-Compat
python3 -B tools/felix_live.py install --root ~/Games/Felix-Live-Compat \
  --installer <官方 Windows 安装器> --assets <本地资产目录>
```

已有安装原地更新（不重下 runner、不重装客户端）：

```bash
python3 -B tools/felix_live.py patch --root ~/Games/Felix-Live-Compat
```

## 回退与关闭

- 拖拽缩放辅助进程：`felix_live.py launch --root <安装目录> --no-ui-resize`
- 渲染后端：默认即 `--ui-renderer default`
- 日志：`$XDG_RUNTIME_DIR/<unit>/ui-resize.log`
