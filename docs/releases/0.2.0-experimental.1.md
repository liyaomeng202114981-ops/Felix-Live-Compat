# 0.2.0-experimental.1：原生 UI 研究源码归档

2026-11-20，用户要求因额度紧张暂停后续开发，将现有修改保存为新版本并同步讨论与可行性。

本版本是**实验源码快照**，基于 `v0.1.0-rc.3.4`，不替换 RC3.4 安装、不提供新的日常兼容二进制、不改变稳定图形参数。它不是从零可安装的 Linux 原生直播伴侣。

## 收录内容

- `experiments/native-ui-demo/`：Linux Electron 自有 UI、独立测试生产者、异步接收及暂停／恢复演示。
- `experiments/wine-sdk-bridge/`：固定版本 SDK helper、独立 Windows 宿主、原产品上下文适配、状态查询、A／B 场景快照与 Linux 显示。
- `experiments/wine-sdk-bridge/results/20261120-initialization.json`：脱敏配置对照、SDK 版本、像素及 UI 自检结果和未验证边界。
- [方案讨论与复杂度](../FEASIBILITY_DISCUSSION.md)、[路线规划与预期效果](../NATIVE_UI_ROUTE_ONE.md)、[具体实现及复跑](../../experiments/wine-sdk-bridge/README.md)。

## 已有证据

官方 Windows 客户端 `13.3.5.564315535`，Windows 引擎 `36.4.0-rs.31.release.lynx41.32`，Linux 引擎 `39.2.7`。独立 SDK 返回 `13.3.5.7`，真实渲染并切换两张 320×180 自有图片；PNG 全部 RGB 像素与各自源图匹配，Linux UI 接收／解码自检通过。

此前最小配置及空 signInfo 触发 metasecml.dll 内 `0xc0000409`。沿用原程序从已安装包取得的产品上下文后通过，没有提供账号／设备标识或修改检查。配置值未进入源码或附件，原始 SDK 日志仅留本机。

本轮发布只做源码／文档／隐私和归档检查，**不重新运行 SDK、GUI、安装、共享、音画或开播测试**。上述结果继承此前已经完成的分项实验。

## 依赖与限制

实验需要用户提供官方安装和匹配的独立 Proton 前缀，本机验证沿用含 0075 的私有接口实验副本；没有新增日常原 GDI32 对照。本附件不包含该私有运行器、Windows 引擎、SDK、厂商资源、产品配置值、账号前缀或日志，不是独立离线运行包。

当前只有快照，不是连续视频、GPU 零拷贝或完整原前端。尚未验证原生架构下的桌面／窗口采集、音画编码和实播，也没有证据宣称完整客户端缩放已经改善。复用标准 Electron 和异步桥不自动保证所有 Windows 插件兼容。

完整日常安装继续使用 [RC3.4](https://github.com/liyaomeng202114981-ops/Felix-Live-Compat/releases/tag/v0.1.0-rc.3.4)。后续开发按可行性文档的顺序恢复，本次不安排自动继续或日常切换。

## 回退与交接

实验 GUI 已停止，不再自动初始化媒体服务。保留源码和私有证据；恢复工作时先读当前版本的讨论、路线及实验 README。无需卸载或重装现有日常版。未修改原 Dock、声音、直连、DNS 或 VPN，也未开播。
