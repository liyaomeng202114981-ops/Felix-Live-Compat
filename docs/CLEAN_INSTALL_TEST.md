# 从零安装验收

验证环境为 Ubuntu 26.04 x86-64、GNOME Wayland、XWayland、PipeWire 和单 render node 的 Vulkan 驱动。安装使用从官网 CDN 取得的 x64 Windows 安装器，以及资产表锁定的 Felix-Proton 运行器。

| 项目 | 当前证据 |
| --- | --- |
| 构建兼容包 | 固定 SteamRT4 SDK 编译 PE 组件，宿主编译 PipeWire worker 和 Vulkan 桥 |
| 旧版安装对照 | `13.2.4` x64 安装器在新前缀安装成功，客户端为 `13.2.4.542841385`。用户扫码进入主界面，点「全屏」后未出现 Ubuntu 共享框 |
| 官方 `13.3.5` 安装器 | Windows x64 安装器的 Authenticode 签名验证通过，签名者为 Douyin Vision Co., Ltd.。第二个新前缀安装后实际运行 `13.3.5.564315535` |
| 启动 | `13.3.5` 候选进入官方主界面。原始辅助进程组合出现界面卡住，关闭辅助进程后用户确认「直播设置」可打开 |
| 显示器 | 独立发起 Ubuntu 授权，PipeWire 多个 2 秒采样窗收到并验证约 320–360 帧。伴侣 GPU 租借数为 0，未验证画布预览 |
| 窗口 | 新前缀点击「窗口」后，未打开 Ubuntu 选择框。缩小辅助程序的窗口扫描范围并单独接入，结果相同 |
| 声音 | 在 `13.3.5` 测试前缀用自有 Win32 探针播放 880 Hz 测试音，从专用 PipeWire/Pulse 监视源回读到同频信号。伴侣本地录制中的音轨尚待核验 |

已验签安装器的 SHA-256 为 `cd8c59735fad840bf6db33b6ea31527b46864bd5169d23e20d134e2132bf020d`。[官方 CDN 下载](https://lf6-cdn-tos.douyinstatic.com/obj/venus/StreamingTool-13.3.5-x64.exe)

媒体进程能看到已授权显示器流的交接套接字，尚未确认它为何没有租借缓冲。移除全部辅助程序后，设置页面恢复响应。仅接回显示器授权进程时，可以继续点击界面，仍未能将画面添加到画布。临时换入日常版 XWayland 组件也未通过，测试后恢复固定运行器。

本轮为本地开发候选，全屏、窗口共享和伴侣内声音录制仍待验收。两轮新前缀测试保持不开播。日常版的既有预览与实播验收见项目历史记录。
