# 全屏与窗口短时实播记录

**历史测试日期：2026-11-18。** 本文整理维护者保留的独立候选验收汇总，没有在本次文档更新中重新开播。原始日志、本地录像和像素／音频测量仅保存在维护者本机，不随兼容包分发。

## 使用的链路

官方 Windows 直播伴侣 13.3.5 运行于独立 Proton／候选前缀。两轮分别从 Ubuntu Portal 授权显示器与原生 Wayland 测试播放器，经 PipeWire DMA-BUF、GPU 裁切／合成与 WGC／D3D11 接入伴侣。测试输入为自有色块、动态帧号、同步闪光和提示音；开播与结束均由用户操作。

## 已验证结果

| 项目 | 全屏 | 窗口 |
| --- | --- | --- |
| 输入 WGC 纹理 | 1920×1080 | 960×540 |
| SDK 推流启动 | 20:47:09.545 | 20:57:14.324 |
| 握手成功 | 20:47:10.143 | 20:57:14.826 |
| 首帧发送记录 | 20:47:11.627 | 20:57:16.451 |
| 正常停止 | 20:47:42.653 | 20:57:42.571 |
| 启动至停止 | **33.108 秒** | **28.247 秒** |
| 同期本地录像 | 1280×720、30 fps、HEVC Main、48 kHz 双声道 AAC-LC，完整解码通过 | 同左 |

时间均为测试当天北京时间。两轮均记录到 TLS 建连、ByteRtmpStream 握手成功、首帧发送和 SDK 正常停止。窗口轮测试素材约占画布左上四分之三宽度，右侧与底部留黑；这是该轮场景布局，未当作满画布验收。

同期本地录像可辨动态帧号与色块。推流重叠时段内，全屏轮 6 组闪光／提示音的音频相对画面中位差为 −23 ms，窗口轮 8 组为 +40 ms。此测量受 30 fps 帧间隔、10 ms 音频检测窗口及录制起点映射影响，仅说明该轮**同期本地录制**的音画关系。

## 验证边界

- 验证对象是伴侣推流端与同期本地录制，未取得观众端播放回录。
- 未验证观众端转码、接收画质与同步，也没有完成长时间推流或真实游戏重负载验收。
- 不能将本地录像的编码格式当作所有实际推流的编码格式。
- 两轮结束后释放 Portal、socket 和候选服务，保留原有回退方案。
